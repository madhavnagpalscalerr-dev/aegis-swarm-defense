# Aegis Swarm Defense

Build a premium, animated website explaining “Aegis Swarm v2.0”, an autonomous cyber-physical drone defense system for rugged Indian swamp terrain. Create a strong landing page with a cinematic hero, clear services/product layers (hardware, edge AI, command center), interactive drone-swarm visuals, threat detection visualizations, a simulated breach experience, use cases (pipelines, communications infrastructure, naval perimeters), outcome/benefit section, Indian enterprise pricing starting ₹12 Lakhs/year, and a compelling CTA. Make the UI exceptionally polished, responsive, dark high-tech, credible for judges and enterprise buyers, with tasteful motion and no need for real backend data.
