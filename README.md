# Aegis Swarm v2.0 - Autonomous Cyber-Physical Perimeter Defense
An automated aerial defense system built specifically for rugged, waterlogged Indian swamp terrains (e.g., the Sundarbans delta) where manual security patrol is impossible.

## 🛠️ System Architecture (3-Layer Infrastructure)
1. **Physical/Hardware Layer:** Ruggedized IP67 amphibious drone swarms using un-jammable point-to-point Laser Communication links instead of standard RF backhauls.
2. **Cognitive/Edge AI Layer:** Low-power math architectures deployed directly on hardware chips to parse multi-sensor signatures offline without relying on external cloud grids.
3. **Decision/SaaS Dashboard:** A centralized corporate command console built on React and Vite for real-time telemetry monitoring, interactive threat simulation, and systemic triage.

## 📊 Core Mathematical Engines
* **Linear Regression ($y = mx + c$):** Tracks real-time wireless network traffic trends to instantly isolate outlier spikes caused by external denial-of-service or injection tracking.
* **Logistic Regression ($\sigma(z) = \frac{1}{1 + e^{-z}}$):** Fuses disparate multi-sensor indicators to calculate a definitive classification probability matrix between 0 and 1.
